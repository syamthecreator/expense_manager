# 💰 Expense Manager

A modern Flutter expense management application that helps users track income and expenses, analyze spending habits, and manage personal finances with a clean, responsive, and intuitive user experience. Built using Clean Architecture with BLoC state management for scalability and maintainability.

## ✨ Features

- 💵 Add, edit, and delete income and expense records
- 📊 Daily, weekly, monthly, and yearly expense tracking
- 🏷️ Expense categorization
- 🔍 Search and filter transactions
- ☁️ Firebase Authentication
- 🔄 Cloud data synchronization with Firebase
- 🔔 Local notifications for payment and bill reminders
- 📈 Financial insights and expense analytics
- 💾 SQLite for offline local storage
- 📱 Responsive UI for Android and iOS
- ⚡ High performance with BLoC state management

## 🛠 Tech Stack

- Flutter
- Dart
- BLoC
- Firebase Authentication
- Cloud Firestore
- SQLite
- Local Notifications
- Clean Architecture
